Study AI is a teaching-first, fully local knowledge framework. The builder starts empty — only common Chinese characters and symbols, zero knowledge — and learns by being taught. build study packs it into a portable .study file your client can use. No cloud, no API, no hallucination. Study AI 是一个教学式、纯本地的知识框架。构建端出生即空壳——只认识中文常用字与符号，没有任何知识——靠被教而学习。build study 把它打包成可移植的 .study 文件，供客户端使用。无云端、无 API、不臆造。

// PRINCIPLE

How it works工作原理

Four steps, exactly as specified. Study AI learns the way a student does — by receiving external knowledge.四个步骤，严格对应原理。Study AI 像学生一样学习——通过接受外部知识。

01

Empty start空壳起步

The builder knows only common Chinese characters + symbols. Zero knowledge.构建端只认识中文常用字 + 符号，没有任何知识。

02

Teach by chat对话教学

You talk; StudyAI records every turn and auto-summarizes what it captured.你对话；StudyAI 记录每一轮，并自动总结已学内容。

03

Build study打包导出

One command packs all history into a portable .study file.一条命令把所有历史打包成可移植的 .study 文件。

04

Use it拿来即用

The client loads .study and answers by retrieval — never inventing.客户端加载 .study，靠检索回答——绝不编造。

// WHY

Built for trust, not tricks为可信而造，而非取巧

Records & summarizes记录与总结

Every teaching turn is logged; knowledge units are extracted and summarized automatically.每一轮教学都被记录；知识单元自动抽取并总结。

Pure local, no API纯本地，无 API

Fully offline heuristics. No keys, no network, zero recurring cost.纯本地启发式。无需密钥、无需联网、零持续成本。

Portable .study可移植 .study

One self-contained file carries the whole knowledge base to any machine.单一自包含文件即可把整个知识库带到任意机器。

Bigram retrieval二元组检索

CJK bigram overlap matches queries; unmatched questions admit "I don't know".中文二元组重叠匹配查询；无匹配时如实说「不知道」。

Light & dark CLI浅 / 深 CLI 主题

Both ends ship a --theme dark|light colored interface.两端均提供 --theme dark|light 着色界面。

Checksum-verified校验和保真

.study validates magic → length → gzip → checksum → version on load..study 加载时校验 magic → 长度 → gzip → 校验和 → 版本。

// FORMAT

The .study file.study 文件格式

A self-describing, checksummed binary container — small, portable, and corruption-aware.自描述、带校验和的二进制容器——小巧、可移植、可识别损坏。
